# 暗棋連棋（Dark Chess Chain）

網頁版台灣半盤暗棋。支援：

- **一般暗棋**與**連棋模式**（吃子後同一顆棋可以繼續吃）
- **單人對電腦**（入門／一般／高手三種難度，可選先後手）
- **同機雙人**（同一台裝置輪流下）
- **線上雙人**（建立房間、輸入 4 碼房號加入）

不需要安裝任何套件，只要有 Node.js 16 以上。

## 怎麼玩

| 用途 | 做法 |
|---|---|
| 只想對電腦或同機雙人 | 直接用瀏覽器開 `dist/dark-chess.html`（單一檔案，可以複製到任何地方） |
| 線上雙人（Claude Artifact） | 開啟發布在 claude.ai 的網頁，選「線上雙人」→「建立房間」，把網頁分享給對手（權限需「參與者」以上），對方開啟後輸入房號加入。棋局透過 Artifact 的共享資料同步，不需要伺服器 |
| 線上雙人（自架伺服器） | `node server/server.js`，用瀏覽器開 `http://localhost:3000`；一人按「建立房間」，另一人輸入房號按「加入」 |
| 讓區網或外網的朋友連線 | 伺服器跑在可連到的主機上，朋友開 `http://<主機IP>:3000`；走 HTTPS 時連線網址改成 `wss://` |
| 修改後重新打包單機檔 | `node build.js` |
| 測試 | `npm test`（規則單元測試 + 電腦自我對弈） |

可用 `node server/server.js 8080` 或環境變數 `PORT` 改埠號。

## 部署成公開網址（任何人用連結就能對戰）

claude.ai 上的網頁不允許「公開連結」進來的組織外訪客寫入資料，所以要讓陌生人只靠連結就能對戰，需要把連線伺服器放到公開主機上：

1. 把整個 `dark-chess` 資料夾放到一個 GitHub repo。
2. 到 [Render](https://render.com) 註冊，選 **New → Blueprint**，選這個 repo，Render 會讀 `render.yaml` 自動建立免費的 Web Service。
3. 部署完成會得到 `https://dark-chess-chain-xxxx.onrender.com` 這樣的網址，打開就能玩，「線上雙人」會自動連到同一個網址。

也可以用任何支援 Docker 的平台（Fly.io、Railway、Google Cloud Run 等），直接用專案裡的 `Dockerfile`。免費方案閒置一段時間後會休眠，第一次開啟要等幾十秒喚醒。

## 規則（採台灣常見玩法）

- 32 子全部蓋著，隨機排在 4 × 8 的棋盤上。先手的人先翻棋，**第一個翻出的顏色就是自己的顏色**。
- 每回合做一件事：翻開一顆暗棋，或把自己的一顆明棋往上下左右走一格。
- 大小順序：帥將 > 仕士 > 相象 > 俥車 > 傌馬 > 炮包 > 兵卒。大吃小，同級可以互吃。
- 例外：**兵卒可以吃帥將，帥將不能吃兵卒**。
- **炮包**：平常一樣走一格；吃子時必須「隔一顆棋」跳吃，中間那顆炮架明暗都可以，距離不限，可以吃任何等級的棋子；不能直接吃相鄰的棋。
- 只能吃已經翻開的棋子。
- **連棋模式（暗棋連吃）**：除了一般規則，明棋還可以攻擊上下左右相鄰的一枚暗棋，翻開後判定：
  - 是「可以被吃掉的敵棋」（階級小於或等於己方，或兵卒對帥將）：吃掉並移過去，可以繼續攻擊相鄰的暗棋。
  - 是自己的棋：連吃停止，翻開的棋留在原地。
  - 是比己方大的敵棋（例如仕士翻出帥將、帥將翻出兵卒）：吃不下，攻擊的棋停在原地，翻開的敵棋也留在原位，回合結束。
  - 連吃途中，同一顆棋也可以吃掉吃得掉的敵方明棋（同級可互吃，先動先吃），吃完還有目標就繼續連吃。不能翻棋或換別顆棋；想停可以按「結束回合」，沒有可吃的目標時自動換手。
  - 回合一開始就吃明棋也一樣：吃完同一顆棋還有目標（暗棋或吃得掉的明棋），就可以繼續連吃。
  - 炮包攻擊暗棋要隔一顆棋（炮架）跳過去，距離不限，不能攻擊相鄰的暗棋；翻出敵棋一律吃掉，翻出自己的棋就停止。
  - 吃已翻開的明棋仍照一般規則，吃完換手。
- 勝負：吃光對方所有棋子，或輪到對方時對方沒有任何合法動作，就獲勝。
- 和局：連續 50 手都沒有翻棋也沒有吃子。

暗棋各地規則差異很大（例如炮能不能吃暗棋、車能不能直線滑行、連吃是否強制），這裡採用上面列出的版本，規則集中在 `shared/engine.js`，要調整很容易。

## 專案結構

```
index.html          網頁（開發時用，由伺服器提供）
client/app.js       介面與操作、線上連線
client/style.css    樣式（支援深色模式、手機直式棋盤）
shared/engine.js    規則引擎（瀏覽器與伺服器共用）
shared/ai.js        電腦 AI
server/server.js    零相依的 HTTP + WebSocket 伺服器
build.js            打包成單一 HTML（dist/）
test/               規則測試、自我對弈
```

## 實作說明

- **防作弊**：自架伺服器模式由伺服器保存真正的棋盤並驗證每一步，傳給玩家的狀態會把暗棋內容遮掉，看原始碼或封包也看不到暗棋是什麼。
- **Artifact 線上模式**：棋局存在 Artifact 共享資料的 `games/<房號>` 文件，雙方即時同步，每一步都在本機驗證規則後才寫入。因為沒有伺服器，懂得開發者工具的人理論上看得到暗棋內容，適合朋友之間玩。
- **電腦 AI**：明棋走法用 alpha-beta 搜尋（入門 1 層、一般 3 層、高手 5 層）；翻棋依「還沒翻開的棋子池」計算期望值。AI 只用公開資訊，不偷看暗棋。連棋模式下會把整串連吃當成一步一起考慮。
- **投降**：對局中按棋盤下方的「投降」（再按一次確認）就直接認輸，結果畫面上按「再來一局」即可開新局；線上模式一局結束後按「再來一局」，雙方會交換先手。同機雙人時由輪到的一方投降。
